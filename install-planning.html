Install Planning & Digital Tools

Plan where your heaters go, then use that layout to plan circuits and materials.

One account for both apps

Create an account in either the Heater Layout or Heater Install app, then use the same email and password to sign in to the other. No need to create a second account.

Step 1: Heater Layout Application

Draw each room to scale, place heater mats, and check floor coverage. Use the room-by-room layout to spot gaps and confirm which mat sizes fit before ordering materials.

Step 2: Heater Installation Application

Use your finished layout as a reference to assign mats to circuits, check wattage and amperage, and plan for thermostats, power modules, and conduit. Then print a materials list for quoting and ordering.
